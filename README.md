# محفظتي الإلكترونية 💰

تطبيق ويب بسيط لتتبع الدخل والمصروفات — يعمل بالكامل في المتصفح بدون حاجة لسيرفر.

## المميزات

- **لوحة ملخص** — عرض الرصيد، الدخل، المصروف، والادخار
- **تصنيفات** — راتب، طعام، مواصلات، فواتير، وغيرها
- **إضافة / تعديل / حذف** عمليات مالية
- **بحث وفلترة** — حسب النوع (دخل / مصروف) أو بالبحث النصي
- **وضع داكن** — تبديل بين الوضع الفاتح والداكن
- **أرشفة الشهر** — حفظ العمليات في الأرشيف بدل مسحها
- **تصدير CSV** — تحميل البيانات كملف Excel
- **تصميم متجاوب** — يعمل على الموبايل والكمبيوتر

## التشغيل

1. افتح `index.html` في أي متصفح حديث
2. أو استخدم Live Server في VS Code

```bash
# أو باستخدام Python
python -m http.server 8080
# ثم افتح http://localhost:8080
```

> **ملاحظة:** ES Modules تتطلب تشغيل عبر HTTP (localhost) وليس `file://`

## التخزين

البيانات تُحفظ محليًا في `localStorage`:
- `transactions` — العمليات الحالية
- `archives` — الأرشيف الشهري
- `theme` — الوضع (فاتح / داكن)
